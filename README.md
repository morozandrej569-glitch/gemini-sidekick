# GeminiSidekick

Лёгкий desktop-ассистент для Windows на .NET 8 (Windows Forms) с плавающим орбом, голосовым вводом (работает плохо), всплывающими подсказками и динамическим запуском приложений через Gemini API.

## Возможности

 Плавающий орб и системный трей — компактный индикатор состояния (`Ctrl+Alt+V` или клик по иконке в трее для голосового ввода, контекстное меню для быстрого доступа к действиям и настройкам).
 Голосовой ввод и распознавание речи (работает плохо) — запись с микрофона в WAV, распознавание русской речи через Gemini API и быстрая отправка команд.
 Динамический запуск программ и ярлыков — поиск по стандартным утилитам, ярлыкам (`.lnk`), исполняемым файлам (`.exe`) и пользовательским папкампутям, а также быстрый локальный запуск команд вида `открой ...`  `запусти ...`.
 Окно настроек (`settings.json`) — добавление и удаление дополнительных папокпутей с программами и ярлыками, настройка паузы тишины перед отправкой (`SilenceMsToSend`).
 Всплывающий пузырь ответов и логирование — показ кратких ответов и статусов выполнения рядом с экраном, запись логов для отладки.

## Требования

 Windows 10  11 (потом будет больше ОС)
 .NET 8 SDK (`net8.0-windows`)
 Переменная окружения `GEMINI_API_KEY` с вашим ключом Gemini API
